01. نبذة عني

مطور برمجيات ومحلل بيانات بخبرة عملية تمتد لأكثر من 6 سنوات في تطوير تطبيقات Android، وإنشاء مواقع وصفحات الويب، وتصميم وإدارة قواعد البيانات، وتحليل البيانات وعرضها بصرياً.

أمتلك خبرة واسعة في Python، C، JavaScript، PHP، HTML/CSS، وSASS/SCSS، مع إجادة استخدام Git وGitHub.

أركز على تحويل المتطلبات والمشكلات إلى حلول تقنية عملية قابلة للتطوير، بدءاً من التخطيط والتطوير وحتى الاختبار والتحسين. وأعمل حالياً على مشروع Zaman-OS — أول لغة برمجة عربية مفتوحة المصدر.

مطور برمجيات ومحلل بيانات

  • تطوير تطبيقات Android وبناء الواجهات والوظائف المرتبطة وربطها بمصادر البيانات.
  • إنشاء وتطوير صفحات ومواقع الويب باستخدام HTML وCSS وJavaScript وSASS وPHP.
  • تصميم وإدارة قواعد البيانات باستخدام PostgreSQL وكتابة استعلامات SQL.
  • تطوير حلول برمجية باستخدام Python وJavaScript وC.
  • تحليل البيانات باستخدام Excel وTableau وإعداد التقارير ولوحات المعلومات.
  • استخدام Git وGitHub لإدارة الإصدارات.
  • معالجة البيانات وتنظيمها وتحويلها إلى معلومات قابلة للاستخدام.
